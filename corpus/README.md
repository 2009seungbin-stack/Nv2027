# corpus — 취향 기준 원고와 대조 샘플

이 디렉터리는 엔진이 **생성하는 텍스트가 아니라 비교 기준** 이다. 시뮬레이터·narrator는 이 파일을
입력으로 받지 않는다. Metallic Auditor(`cte.audit`)가 기준선 프로필을 만들 때만 읽는다.

| 파일 | 출처 | 용도 |
|---|---|---|
| `reference/massage_001.txt` | 저장소 소유자 본인의 원고(「마사지 해드립니다」 1화), 교보재로 저장 허락 | 사람이 쓴 기준 원고 |
| `reference/massage_001.annotations.json` | 분석 주석 | 장치별 인용·범주·CTE 대응 층·학습 대상 여부 |
| `contrast/massage_001_llm_default.txt` | **합성**(Claude가 LLM 기본값 경향을 일부러 모아 씀) | 대조군 — 원고가 아니다 |
| `tuning/rin_gift/` | Claude 원고 + 작가 반응(원문) | 조율 기록 — 집필 때는 `final.txt` 만 본다. 자세한 건 폴더 README |

## 원고 표기 규약

원문을 그대로 옮기되, 웹페이지 렌더링에서 사라진 구조만 최소한으로 표시한다.

- `# ` 로 시작하는 첫 줄: 회차 제목
- `> ` 로 시작하는 줄: 원문 웹페이지의 UI 박스(문자 알림). 텍스트는 원문 그대로
- `=====` 로 둘러싸인 구간: 원문의 시스템(퀘스트) 창
- `---`: 원문의 장면 구분
- 제외한 것: 웹페이지 UI 잔재("글자 17px")
