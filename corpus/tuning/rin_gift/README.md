# rin_gift — 린 루트 N화 「매니저 오빠 생일이라서」 조율 기록

Claude가 쓴 원고를 작가가 여러 차례 되돌려 보낸 기록이다. 규칙 문서가 아니다.

| 파일 | 내용 |
|---|---|
| `brief.md` | 작가 요청 원문 |
| `final.txt` | 마지막 판. 작가가 추가 수정 없이 "앞으로도 이렇게 쓰는건가"라고 물은 판 |
| `rounds/v1.txt` ~ `v7.txt` | 되돌려진 판들(순서대로) |
| `reactions.md` | 각 판에 대한 작가의 말, 원문 그대로 |

## 쓰는 법

- **집필할 때**: 문체 기준은 작가 원고 `corpus/reference/massage_001.txt` 다. `final.txt` 는 Claude가 쓴 통과본이라
  문체 기준으로 삼지 않고, 린 루트를 이어 쓸 때 인물 목소리·연속성 확인용으로만 본다.
  `reactions.md` 와 `rounds/` 는 집필 중에 읽지 않는다. 읽으면 피할 목록을 채우는 글이 된다.
- **다 쓴 뒤 점검할 때**: 초고를 `rounds/` 의 되돌려진 판들과 나란히 놓고, 어느 판과 닮았는지를
  `reactions.md` 의 작가 말과 함께 작가에게 보여준다. 자동으로 고치지 않는다.
- 작가 말을 요약하거나 규칙 목록으로 옮겨 적지 않는다. 새 반응이 생기면 원문 그대로 `reactions.md` 에 덧붙인다.
