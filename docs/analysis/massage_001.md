# 「마사지 해드립니다 001」 해체 분석 — 사람이 쓴 원고 vs LLM 기본값

- 기준 원고: `corpus/reference/massage_001.txt` (저장소 소유자 본인 원고)
- 대조 샘플: `corpus/contrast/massage_001_llm_default.txt` (합성 — 같은 도입부를 LLM 기본값 경향으로 쓴 것)
- 장치별 주석: `corpus/reference/massage_001.annotations.json` (인용은 테스트가 원문과 글자 단위로 검증)
- 수치 재현: `cte prose-profile corpus/contrast/massage_001_llm_default.txt`

## 요지

이 원고가 잘 읽히는 이유는 문장의 아름다움이 아니다(상투어도 있다). **설계, 인물 내면의 비일관성,
목소리, 박자**다. LLM 기본값이 무너지는 곳도 대부분 문장 층이 아니라 이 층이다. 그래서 CTE 원칙 14
("맛이 부족하면 prose를 꾸미지 말고 압력·결정·충돌 층으로 돌아간다")가 이 원고로 그대로 확인된다.

## 2. 설계 층

1. **제목이 결말을 밝힌다** — "스팸 문자인 줄 알았는데, 주식이 박살났다". 독자는 폭락을 알고 "장난이네"를 본다.
   사건이 문자 한 통뿐인데도 긴장이 유지되는 이유(극적 아이러니).
   LLM 기본값: 결과를 숨기고 순서대로, 복선은 "그때까지만 해도 몰랐다"로 따로 강조.
2. **퀘스트가 검증 가능한 게임 규칙** — 손 마사지 · 최소 1,000원 · 12시간 · 벌칙. 해법(후배, 스팀피처, "손재주가 좋은 편")을
   같은 화에 깔아 두고 인물은 연결하지 못한다. 연결은 독자 몫. LLM 기본값: 인물이 규칙을 분석하고 "일단 해보기로 했다".
3. **설명하지 않는 잡음** — "이것도 연구해봐", 15자리 번호, "정성스럽게 칸을 띄워놨기에". LLM 기본값: 모든 디테일을 해명.
4. **생각이 결론 없이 끊긴다** — "근데 단순한 우연으로 치부하기엔 뭔가…" → "선배! 선배선배선배!!".
   LLM 기본값: 사색을 정리 문장으로 닫고 장면 전환.
5. **과거는 현재 단어가 불러낼 때만, 현재 의심의 증거로** — '마사지' → 조부모 안마 → "하민이 말고는 말해준 적이 없는데".
   LLM 기본값: 도입부 설정 덤프, 또는 질문 없는 회상.

## 3. 인물 층

6. **자기모순이 개그** — "장난 문자를 머릿속에서 지워냈다" → 장면 구분 → "아나… 진짜 누구지?".
   LLM 기본값: 일관된 감정 궤적 + 감정 명명("묘한 불안감이 가슴 한켠을 스쳤다").
7. **증거와 신뢰의 충돌** — 하민만 아는 이야기 vs "절대로 이런 장난을 칠 녀석도 아니거니와". 결론 없이 거슬림으로 남는다.
8. **실리적 내면** — 시선을 거두는 이유가 윤리가 아니라 "이 꿀 같은 알바 자리". 하려다 멈춘 행동 + 이기적 이유.
   LLM 기본값: 위생 처리 또는 도덕적 교정.
9. **구체적 판돈** — 군대에서 모은 돈, 천만 원 이상, 수익률 15%, 추매, "효자 녀석", "우리 엔디".
10. **목소리 = 나이·계층·관심사** — 주식 은어, 욕설, "개인정보가 그냥 공공재라니까". LLM 기본값: 중립 문어체.

## 4. 문장 층

11. **한 문장을 행동 사이에 걸쳐 완성** — "허나, 차마 손을 쓰기엔 너무…" → 대사 세 줄 → "너무 예쁘잖아. 망할."
12. **썰렁한 기성 아재개그 + 무표정 반응, 해설 없음** — "아야어여오요우유"(2회) → "……." → "…하." → "진심으로 죽이고 싶다…".
    LLM 기본값: 무난한 농담 + "나도 모르게 웃음이 새어 나왔다".
13. **의도적 반복** — "신경이 쓰였다" 2회, "어쩐지" 2회("왜인지는 모르겠지만, 어쩐지."). LLM 기본값: 동의어 돌려막기.
14. **표기 자체가 연기** — "선배선배선배!!", "후흐흐흐흐흐흐흫", "넹", "쏘리~".

## 5. 배우지 않는 것 (주석 `category: noise`, `learn: false`)

- 맞춤법·띄어쓰기("메세지", "말 하지")
- 히로인 외모 체크리스트와 상투어("백옥같이 새하얀 피부")
- 신체 부위 응시 묘사 — 배울 것은 내용이 아니라 "하려다 멈춘 행동 + 이기적 이유" 구조뿐

## 7. Metallic Auditor (`cte.audit`)

문장을 고치지 않고 **되돌아갈 층** 을 가리킨다.

- 문장 층 신호(`prose.compare`): dense_paragraphs · uniform_paragraphs · emotion_labeling · simile_density ·
  explained_joke · all_sentences_closed · repetition_avoided → narrator / summary_closer → **collision** /
  abstract_stakes · no_concrete_numbers → **state**
- 구조 진단(`structure.audit_scene`, 원장 읽기 전용): no_world_interruption → world · no_failure → pressure ·
  no_wavering → residue · no_misbelief · abstract_desires → state · no_alternatives · monotone_actor → decision

현재 데모 장면 진단 결과: 세계 중단·실패·흔들림·오신념은 있으나 **monotone_actor**(규칙 기반 제안기가 같은 행동을 반복)가 잡힌다 —
LLM 제안기(`--llm`)로 바꿔야 할 근거.
